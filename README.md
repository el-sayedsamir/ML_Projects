# Machine Learning Projects

A collection of machine learning projects built with Python and scikit-learn. Each project lives in its own folder with a notebook, the dataset, saved plots, and a README that explains the approach and results.

## Projects

| # | Project | Model | Key Result |
|---|---------|-------|------------|
| 01 | [House Price Prediction](./01-linear-regression-house-prices) | Linear Regression | R² = 0.91 on the test set |

More projects will be added over time.

## Repository Structure

```
ML_Projects/
├── README.md
├── requirements.txt
├── 01-linear-regression-house-prices/
│   ├── README.md
│   ├── notebook.ipynb
│   ├── data/
│   └── images/
└── ...
```

Every project folder follows the same layout, so each one can be opened and understood on its own.

## Tech Stack

Python, pandas, NumPy, scikit-learn, Matplotlib, Jupyter Notebook.

## How to Run a Project

1. Clone the repository.
2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open the project folder and run `notebook.ipynb` from top to bottom.
